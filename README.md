# Asteroids 2D (Quadtree Collision Detection)

Аркадная игра «Астероиды 2D» и физическая симуляция упругих столкновений на базе пространственного разбиения **квадродеревом (Quadtree)** без полного перебора объектов.

## Возможности
- Поиск столкновений (шар–шар, снаряд–шар, корабль–шар) с помощью динамического квадродерева.
- Визуализация границ узлов квадродерева в реальном времени.
- Физика абсолютно упругих столкновений с учетом массы объектов ($m = \pi R^2$).
- Графический интерфейс настройки параметров (количество, размеры, скорости, размер окна).
- Управление кораблем, стрельба, раскалывание крупных астероидов и система жизней.
